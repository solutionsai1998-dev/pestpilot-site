# PestPilot Marketing Site

Public marketing site for PestPilot at `pestpilot.app`.

## Legal Copy

The rendered legal pages in this repo must stay in sync with the app repo legal source files:

- `app/terms/page.tsx` mirrors `../pestpilot/legal/terms-of-service.md`
- `app/privacy/page.tsx` mirrors `../pestpilot/legal/privacy-policy.md`
- `app/cancellation/page.tsx` mirrors `../pestpilot/legal/cancellation-policy.md`

Update both repos in the same change whenever legal, pricing, SMS, refund, cancellation, or data-retention copy changes.
